# Steps 🪜

Transforme tarefas em jornada: cole um checklist, vire um passo a passo visual e acompanhável — ou visualize tudo como um mapa mental.

## Como usar
1. Abra `index.html` no navegador (não precisa de servidor nem dependências).
2. Clique em **Criar processo**, dê um nome, escolha um ícone e cole sua lista:
   - `- [ ] item` (checklist markdown)
   - `1. item` (numerada)
   - `- item` ou linha simples
3. Clique no card para entrar na jornada: um passo por vez, com anel de progresso, confete ao concluir e tela de vitória ao final.
4. No menu do card (⋮) você pode **ver o mapa mental**, editar ou excluir.

## Recursos
- Parser de checklist (markdown, numerado, bullets)
- Modo jornada: um passo por vez, anterior/próximo, pular entre passos, desmarcar
- Progresso salvo automaticamente (localStorage)
- Mapa mental em canvas: nós arrastáveis, duplo clique marca/desmarca o passo, botão reorganizar
- Confete ao concluir passos e na finalização
- Interface limpa, animada e responsiva, 100% em português

## Stack
HTML + CSS + JavaScript puro, arquivo único, zero dependências.
